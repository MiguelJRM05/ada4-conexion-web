HTML, CSS y JavaScript

Comparación de tecnologías utilizadas en este sitio
TecnologíaFunciónEjemplo en el proyecto
HTMLEstructura y significado del contenido.Títulos, listas, tabla y formulario.
CSSPresentación y adaptación a distintos tamaños.Menú, colores, línea del tiempo y estados de enfoque.
JavaScriptComportamiento y respuesta a eventos.Validación de los controles del formulario.
Las tecnologías de FrontEnd se complementan con PHP y MySQL en las páginas dinámicas de este sitio.

HTML: organizar

Una estructura con significado

Los elementos header, nav, main y footer delimitan las partes de cada página. Los títulos siguen los niveles h1, h2 y h3.

CSS: presentar

Diseño compartido

Una hoja externa define el estilo de todas las páginas. Las reglas :hover y :focus-visible dan respuesta visual al menú sin utilizar imágenes.

JS: interactuar

Comprobar las entradas

El evento submit activa la revisión de campos. Los errores se muestran junto al control correspondiente para facilitar su corrección.
