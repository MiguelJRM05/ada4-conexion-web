La web también es responsabilidad.

Crear una página implica pensar en las personas que la van a usar.

01

Participación

De leer a colaborar

Blogs, wikis y comunidades permiten que los usuarios publiquen, comenten y colaboren. La expresión web social describe esta participación.

02

Accesibilidad

Más formas de navegar

Una página debe poder recorrerse con teclado y ofrecer etiquetas, textos alternativos y contraste suficiente. Las pautas WCAG orientan este trabajo.

03

Privacidad

Datos con un propósito

Conviene pedir únicamente la información necesaria y explicar para qué se utiliza. Este sitio dispone de un formulario educativo que puede guardar registros ficticios en una base de datos local mediante PHP. No debe usarse para enviar información real.

Cómo se aplican estas ideas aquí

  • El menú mantiene los mismos enlaces en todas las páginas.
  • Los elementos enfocados tienen un contorno visible.
  • La ilustración incluye una descripción alternativa.
  • El formulario explica los errores con texto.
  • El diseño reorganiza sus columnas en pantallas pequeñas.

Una reflexión

La evolución de la web no se limita a agregar funciones: también requiere construir experiencias comprensibles, inclusivas y útiles. Una interfaz con inteligencia artificial necesita los mismos cuidados de accesibilidad que cualquier otra interfaz.
