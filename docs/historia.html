Línea del tiempo de la web

Los puntos y la línea conectan los acontecimientos en orden cronológico. La última entrada describe tendencias, no una nueva versión oficial de la web.

  1. 1989

    La propuesta inicial

    Tim Berners-Lee propone en el CERN un sistema de información enlazada.

  2. 1990

    Primer navegador y servidor

    Se implementan WorldWideWeb y el primer servidor web.

  3. 1991

    La web se comparte

    El proyecto se anuncia en Internet y amplía su alcance fuera del CERN.

  4. 1993

    Mosaic

    El navegador gráfico facilita explorar páginas con contenido visual.

  5. 1993

    Una tecnología abierta

    El CERN libera el software de la web al dominio público el 30 de abril.

  6. 1994

    Nace el W3C

    Se funda el consorcio para impulsar estándares de la web.

  7. 1995

    HTML 2.0

    Una especificación organiza las características básicas del lenguaje.

  8. 1997

    HTTP/1.1

    El protocolo mejora la comunicación entre navegadores y servidores.

  9. 2001

    Wikipedia

    La enciclopedia colaborativa muestra el potencial de crear contenido entre personas.

  10. 2005

    YouTube

    El video compartido se convierte en una forma de participar en la web.

  11. 2014

    HTML5

    La recomendación incorpora elementos semánticos y multimedia.

  12. 2015

    HTTP/2

    Una nueva versión del protocolo permite transportar datos de manera más eficiente.

  13. 2023

    WCAG 2.2

    Nuevas pautas amplían los criterios de accesibilidad del contenido web.

  14. Actualidad

    Una web para más personas

    Las experiencias móviles, el contenido multimedia y las interfaces con IA refuerzan la necesidad de accesibilidad.
